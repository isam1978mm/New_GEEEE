## Result

The exact-identifier search recovered the already-known official/public records, principally:

1. the Virginia DEQ March 2020 West Ash Pond CQA report identifying Flora Surveying Associates and the Bremo closure work; and
2. later Dominion/Golder Bremo figures that state pond-area existing conditions were compiled from multiple field surveys by H&B Surveying & Mapping, Flora Surveying Associates, Ryan Construction, and Glover Construction collected from 2017 through 2020.

No indexed/downloadable public result exposed:

- a `RYAN-BREMO` point file;
- an original `VC-01` CAD or point export;
- an original `CBR-01` CAD or point export;
- an original `CBR-02` source table/surface;
- DWG/DXF/LandXML/TIN corresponding to the Flora Appendix A sheets;
- a Flora-to-Ryan/Dominion/Golder electronic survey transmittal;
- a source survey filename that can be independently downloaded.

The search therefore did not advance beyond the published survey drawings already recovered in Appendix A.

## Important public-record distinction

Other Bremo engineering drawings do expose internal **Golder** DWG paths, proving that CAD-path metadata exists in some published project records.

That is not the same as finding the original **Flora `RYAN-BREMO` survey data**. No public search result exposed a Flora source path or machine-readable survey file for `VC-01`, `CBR-01`, or `CBR-02`.

## F186 decision

### Public recovery of original Flora source survey: FAIL / EXHAUSTED ON CURRENT INDEXED EVIDENCE

Do not repeat broad web searches for the same identifiers unless a genuinely new public record appears.

This is an **access result**, not a scientific rejection of the survey. The survey truth remains valid and published; only the original electronic geometry remains unavailable publicly.
