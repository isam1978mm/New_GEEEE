# Depth Source Data Request Packet — 2026-07-20

Status: request drafts prepared; no messages sent and no calibration records approved.

These drafts support the private local depth-research workflow. They ask only for benign controlled-site records, provenance, uncertainty, and research-use terms. They do not claim that any source is already suitable for Sentinel-1 depth calibration.

## Shared request objective

The project is seeking independently documented controlled-site records for cautious method research. The minimum useful package contains:

```text
- target construction or installation table
- exact depth-reference definition
- numerical survey and placement uncertainty
- target dimensions, material, and orientation
- raw geophysical files and format documentation
- acquisition dates and profile-to-target mapping
- pre-installation or independently verified background data
- licence or written permission for private research use
```

All received files must remain privately versioned until provenance, privacy, scale, and scientific-eligibility review is complete.

## Decision rules after a response

```text
complete source package + usable uncertainty + eligible scale
    -> continue private qualification

complete ground-method package but satellite scale unsupported
    -> ground-method validation only

known depths but no uncertainty
    -> hold; do not import until uncertainty policy is defensible

raw signals but depth derived from the same signals
    -> method research only; not independent ground truth

same-site background only
    -> local control; not independent confirmed-negative holdout

unclear licence or permission
    -> hold; do not use beyond source review
```
