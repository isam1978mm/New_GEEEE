# Tyrone depth — F159 quarterly PDTI Pit-map closure — 2026-08-20

## Purpose

Screen the newly exposed quarterly PDTI "Pit maps" record class as a possible late-2004 source for the missing immediate post-grading / pre-cover Tailing Dam 3X surface.

## Source evidence

The official October-2004 supplemental materials characterization report describes PDTI "Pit maps" as:

- reflecting mine-wide changes in **pits and stockpiles**;
- developed quarterly by PDTI since 1973;
- available as hard-copy maps for selected historical periods;
- digitized by Greystone / DDS, Inc. with elevation attribution to plateau, toe, crest and contour features.

The same source provides an explicit spatial-extent table for the Pit-map-derived topography. The listed units are active pits and rock/leach stockpiles, including Main Pit, Valencia Pit, East Main, Gettysburg, Copper Mountain, San Salvador Hill, South Rim/Savanna and multiple numbered stockpiles.

**Tailing Dam 3X is not listed in the spatial extent for the Pit-map-derived topography.**

The same table separately identifies the 1995–2004 PDTI Engineering AutoCAD topography as **"Tyrone Mine full extent"**, attributed to D. Benavidez and supplied May 3, 2004.

## Search result

Targeted repository and public-web searches did not recover a Q4-2004 quarterly Pit map that independently demonstrates coverage of the 3X tailings top surface.

The phrase "mine-wide changes" cannot override the source's own narrower definition: changes in pits and stockpiles. Tailing Dam 3X is a tailing impoundment, not one of the Pit-map spatial units listed in the source table.

## Decision

**F159 — QUARTERLY PDTI PIT-MAP ROUTE CLOSED AT THE SPATIAL-RELEVANCE GATE.**

Even if a Q4-2004 Pit map existed, it cannot be promoted to a 3X pre-cover surface without evidence that the map class actually surveyed and carried elevation geometry across Tailing Dam 3X. No such evidence was recovered.

Do not interpolate a 3X surface from distant pit/stockpile contours.

Do not treat the word "mine-wide" as proof of Tailing 3X coverage when the same source explicitly limits the Pit-map changes to pits and stockpiles.
