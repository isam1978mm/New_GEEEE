# Vista Pointe Landfill Area C depth-pair result - 2026-07-27

## Decision

**NOT GOOD TO GO**

The ArcelorMittal Cleveland Vista Pointe Area C closure package is a strong full-scale construction record. It includes a large closure footprint, professional construction quality assurance, as-built record drawings, certified cover materials, and thickness verification.

However, it does not contain two comparable depth conditions.

## Recovered construction evidence

Area C is approximately 16.5 acres. Closure construction was substantially completed in October 2020 and the completed area was seeded.

The certified cover assembly consists of:

```text
geosynthetic clay liner
40 mil HDPE geomembrane
geocomposite drainage layer
12 inches slag fines
12 inches vegetative soil
```

The total protective cover is therefore 24 inches, or 2 ft.

The project received a variance reducing the permitted 3-ft protective cover to 2 ft for Area C. GPS-guided placement and construction surveys were used to verify the completed protective-cover thickness.

## Fatal problem

The whole full-scale vegetated Area C closure cap uses the same 2-ft protective-cover design.

The only thicker locations are associated with:

- internal construction haul roads;
- terraces;
- perimeter drainage;
- stormwater-control features.

Those are infrastructure features with different compaction, geometry, roughness, and drainage behavior. They cannot serve as a clean same-surface deeper comparison zone.

The package also identifies Area C as the first closure cap constructed at Vista Pointe, so the record does not provide a neighboring older vegetated closure area with a different certified thickness.

## Calibration decision

```text
full-scale area = yes
vegetated final surface = yes
final as-built record drawings = yes
surveyed thickness verification = yes
clean interior width in Area C = likely sufficient
second large same-surface measured depth zone = no
usable calibration row created = no
Earth Engine query executed = no
app depth enabled = no
```

Final decision:

```text
NOT_GOOD_TO_GO_NO_SECOND_COMPARABLE_DEPTH_ZONE
```

## Next step

Continue the approved search only with completed full-scale vegetated closure packages that contain two certified thickness zones, or a certified positive/negative pair, each retaining 30-40 m clean interior width after excluding infrastructure.
