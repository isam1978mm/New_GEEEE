# Phase 0 Notebook Parity Output Inventory Lock

## Purpose And Scope

The objective is faithful notebook-to-Python-app conversion. Phase 0 locks the documentation/data inventory of notebook output families the Python app must track for notebook parity. This is docs/data only: no pipeline code, API behavior, frontend behavior, database model, test, runtime, output rename, or artifact-serving behavior is changed by this document.

Original notebook names are preserved for parity where technically feasible, including names that are experimental, oddly named, duplicate, Colab-specific, coordinate-bearing, or unsuitable for public UI. This inventory records those names as parity output names, not as product claims.

File existence is not parity proof. Source-file inspection can identify writer code paths, artifact classes, and path mappings, but runtime output presence and notebook-value parity remain unverified unless a real run/reference comparison verifies them.

`app/pipeline/stages/secret_layers.py` is classified as a notebook-parity semantic raster stage. `app/pipeline/stages/report_640.py` is classified as a notebook-parity report/semantic raster stage. They are not clean defensible core by default.

Classifier/model interpreted outputs must use probability-only wording. Future interpreted classifier outputs may express class probabilities, probability bands, heuristic scores, uncalibrated model probabilities, or calibrated model probabilities; they must not use confirmation wording.

## Mode Separation

| Mode | Purpose | Output handling |
|---|---|---|
| Core app mode | Stable app-native workflow, run lifecycle, artifact tracking, controlled API/frontend behavior. | Uses app-native names and current artifact policy. |
| Notebook parity mode | Preserve notebook output families, names, folders, aliases, reports, QA, and comparable local output tree. | May write notebook-compatible aliases such as `DEM_GEO8_TIFS/*`, `GEOTIFF_RADAR_BANDS/*`, `NPY_STACKS/*`, `REPORT_640_*`, and `AI_READY_*`. |
| Experimental/private mode | Preserve classifier/model-derived notebook behavior and local-only class-probability outputs. | Writes under private/local trees such as `experimental/`; outputs remain `FILESYSTEM_ONLY`. |
| Public/shared mode | Future controlled sharing of redacted summaries only. | Separate later decision; parity artifacts are not automatically public. |

## Notes For Later Phases

Phase 0 does not decide what belongs in public/shared mode. Parity/private files can exist without becoming API, frontend, tile, preview, or download products.

Statuses in `docs/parity_expected_outputs.json` are intentionally conservative. When writer code exists but runtime output presence or notebook-value parity was not verified in this task, the status is `unknown_needs_verification` or `partial`.
