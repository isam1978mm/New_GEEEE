# Temporary Meredosia CQA extractor

This branch contains one-off evidence-recovery tooling for Ameren's public Meredosia Construction Quality Assurance report. It discovers the linked PDF from the official facility page, indexes the report, and renders survey/as-built/closure pages for manual review.

It does not call Earth Engine, create calibration records, train a model, or enable depth output. The tooling will remain unmerged unless it produces reusable, validated evidence-processing code.
